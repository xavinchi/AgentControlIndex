# Agent Control Index

Build a static GitHub Pages web app that benchmarks tools whose core function is agent control, governance, observability, security, auditability, policy enforcement, human oversight, and runtime control.

Audience:
CIOs, CTOs, enterprise architects, AI governance leaders, senior consultants.

Stack:
Vite, React, TypeScript, Tailwind CSS, Recharts.

Design:
FT-inspired editorial intelligence product. Warm paper background, serif headings, dark ink text, burgundy accents, dense elegant tables. Do not use FT logos, proprietary fonts, or copied assets.

Data:
Static JSON files in /public/data. First version uses human-researched sample data. Future version may pull live public data.

Scoring:
Enterprise governance-led. 0–5 score per dimension, weighted to 100.

Dimensions:
- runtimePolicyControl: 20
- identityAccessPermissions: 15
- observabilityAuditability: 15
- riskComplianceGovernance: 15
- humanOversightApprovals: 10
- toolActionControl: 10
- enterpriseIntegrationReadiness: 10
- evidenceQualityMarketMaturity: 5

Score bands:
85–100 Leader
70–84 Strong Performer
55–69 Emerging Contender
40–54 Early Stage
0–39 Limited Evidence

Pages:
Market Overview, Benchmark, Tool Profile, Trend Explorer, Methodology, Research Input, Report Export.
